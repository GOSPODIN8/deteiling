# HAYANMI DETEILING: учёт денег в Telegram

Мини-приложение в Telegram для детейлинг-центра: заказы, расходы, касса, партнёры, зарплаты и отчёты. Бот каждый вечер присылает итог дня, по понедельникам — итог недели, 1-го числа — итог месяца с делёжом прибыли.

## Что умеет (этап 1)

- **Заказы:** услуги с договорной ценой, кузов, машина и госномер, клиент, один или несколько мастеров, оплата наличными, на карту или через терминал, частичная оплата и долги.
- **Расходы:** по категориям, из кассы, с карты или из своих денег, с фото чека.
- **Деньги:** остатки в кассе, на карте, в терминале и у каждого партнёра на руках, плюс переводы между ними.
- **Партнёры:** вложения. Прибыль сначала возвращает вложения, потом делится по долям.
- **Зарплаты:** оклад и/или % с заказа, авансы. Если на машине работали несколько мастеров, их часть делится поровну.
- **Отчёт за месяц, журнал действий, настройки:** команда, услуги, категории, счета.

## Как запустить: GitHub и Railway

### 1. Создайте бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя, например `HAYANMI Касса`, и username, например `hayanmi_kassa_bot`.
3. BotFather пришлёт **токен** вида `7712345678:AAH...`. Сохраните его, он понадобится на шаге 4.

### 2. Узнайте Telegram ID партнёров

Каждый партнёр пишет боту [@userinfobot](https://t.me/userinfobot) и получает свой ID, например `123456789`. Соберите ID всех партнёров.

### 3. Загрузите код на GitHub

1. На [github.com/new](https://github.com/new) создайте репозиторий, например `hayanmi-app`, тип **Private**.
2. На странице репозитория нажмите **uploading an existing file**.
3. Распакуйте архив и перетащите в окно **всё содержимое** папки `hayanmi` (файлы и папки `server`, `web` и т. д.), а не саму папку.
4. Нажмите **Commit changes**.

### 4. Разверните на Railway

1. На [railway.com](https://railway.com) нажмите **New Project → Deploy from GitHub repo** и выберите `hayanmi-app`.
2. В проекте нажмите **Create → Database → PostgreSQL**.
3. Откройте сервис приложения, вкладка **Variables**, и добавьте переменные:

   | Переменная | Значение |
   | --- | --- |
   | `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` (Railway подставит адрес базы) |
   | `BOT_TOKEN` | токен из шага 1 |
   | `OWNER_TELEGRAM_IDS` | ID партнёров через запятую: `123456789,987654321` |
   | `NODE_ENV` | `production` |

4. Вкладка **Settings → Networking → Generate Domain**. Появится адрес вида `hayanmi-app-production.up.railway.app`.
5. Нажмите **Deploy**, если Railway не начал сам. В логах должно появиться `HAYANMI запущен на порту ...`.

### 5. Откройте приложение

Откройте своего бота и нажмите **Старт**. Внизу слева появится кнопка **Касса**: она открывает приложение. Если кнопки нет, закройте и снова откройте чат.

Каждый партнёр тоже должен нажать **Старт**, иначе бот не сможет присылать ему итоги.

## Как добавить нового человека

1. Человек пишет боту `/id` и присылает вам номер.
2. В приложении: **Ещё → Настройки → Команда → Добавить**. Впишите ID, имя и роль.

## Первые настройки

1. **Команда:** доли партнёров в % и схема зарплаты (оклад и/или % с заказа).
2. **Партнёры → Вложение:** кто сколько вложил в запуск.
3. **Услуги и прайс:** при желании впишите цены-подсказки для седана, кроссовера и джипа.
4. **Счета:** если карт несколько (Алиф, Душанбе Сити), добавьте каждую отдельным счётом.

## Если что-то не работает

| Что видно | Что сделать |
| --- | --- |
| «Нет доступа. Ваш Telegram ID: …» | Добавьте этот ID в `OWNER_TELEGRAM_IDS` или через «Настройки → Команда». |
| «Откройте приложение из Telegram» | Приложение работает только внутри Telegram, через кнопку «Касса». |
| Нет кнопки «Касса» | Проверьте, что домен создан (шаг 4.4), и перезапустите деплой. |
| Ошибка про `DATABASE_URL` | Проверьте переменную `DATABASE_URL = ${{Postgres.DATABASE_URL}}`. |
| Итоги не приходят | Партнёр должен нажать «Старт» в боте. Итог дня приходит в 21:00 по Душанбе. |

## Для разработчика

- Node.js 20+, сервер без фреймворков (`node:http`), PostgreSQL через `pg`, интерфейс на React, сборка через esbuild.
- `npm install && npm run build && npm start`
- Таблицы создаются автоматически при запуске (`server/src/migrations.ts`).
- Локально без Telegram: `NODE_ENV=development DEV_TELEGRAM_ID=111 OWNER_TELEGRAM_IDS=111`, затем открыть `http://localhost:3000`.
- Необязательные переменные: `APP_URL` (адрес приложения, если не Railway), `DAILY_REPORT_HOUR` (час итога дня, по умолчанию 21).
